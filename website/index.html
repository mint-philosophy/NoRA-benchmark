The idea

Beyond choosing
a plausible action.

In everyday situations, an agent is not handed a menu of possible actions. It has to notice what matters, identify reasonable next steps, and explain why those steps fit the situation.

NoRA turns this into an open-ended evaluation task. Models propose actions from first-person visual context, linking each action to supporting reasons and each reason to scene facts. Multiple actions can be reasonable; the benchmark evaluates both the candidate set and its support.

03 / Evaluation

Three questions.
One grounded assessment.

A good action, the relevant facts, and the right support must work together.

A

Action alignment

Does the model recover reasonable candidate next actions?

action_f1
F

Factual grounding

Does it identify the relevant scene facts in the reference support graphs?

fact_f1
S

Support binding

Are facts and reasons connected to the appropriate actions?

reasoning_f1

R = 3√A · F · S

Grounded reasonableness combines the available components with a geometric mean per clip. Reported scores average across valid clips, using soft or one-to-one Hungarian alignment.

What this score means. Agreement with reviewed references, not universal moral correctness or a safety guarantee. Invalid and missing predictions are reported separately. Model comparisons use the same valid clips and must include coverage.

From the paper

Seeing the scene
is not the whole task.

01

Actions need their own support.

A relevant fact or plausible action is not enough when the reason is attached to the wrong next step.

02

More structure is not a universal fix.

Deliberate and structured prompting show model-specific trade-offs, rather than one consistently winning recipe.

03

The candidate set matters.

Selecting one defensible action and recovering the broader space of reasonable actions are distinct evaluation targets.

04 / Use NoRA

Bring your model.

Use pre-action frames or video, connect a model callback or compatible API, or evaluate saved predictions.

Score annotation-format predictions
uv sync --locked --extra scorer
uv run nora validate predictions.jsonl
uv run --extra scorer nora evaluate \
  --predictions predictions.jsonl \
  --output runs/my-model

Start with the provided visual inputs and prompts, generate model responses, then reconstruct and score them. The package includes test references.
